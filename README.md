# 🎲 Dice Game

A simple and fun two-player dice game built with **HTML**, **CSS**, and **JavaScript**. The game is fully responsive and includes a clean UI, basic animations, and a rules modal to help new players understand how to play.

---

## 🕹️ Game Rules

1. The game has 2 players, playing in rounds.
2. Each turn, a player rolls a dice as many times as they wish. Each result adds to their current score.
3. BUT if the player rolls a 1, they lose their **current score** and the turn passes to the other player.
4. The player can choose to "Hold", which adds their current score to their **total score**, then it's the next player's turn.
5. The first player to reach **100 points** wins the game.

---

## ✨ Features

- 🎯 Clean and responsive design
- 📱 Mobile-friendly layout
- 🔄 "New Game" button to restart the game
- 🎯 Visual indicators for the active player
- 🎨 Color changes on small screens to highlight the current player
